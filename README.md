# Сайт СТО и шиномонтажа «Гараж №1»

Сайт-визитка автосервиса: услуги, прайс, преимущества, отзывы, контакты и форма обратного звонка.

## 🔗 Открыть сайт

**https://alexandr-mironov64.github.io/site-mironov/**

## Структура проекта

- `index.html` — главная страница (услуги, прайс, отзывы, контакты, форма)
- `styles.css` — стили
- `app.js` — интерактив: мобильное меню, маска телефона, валидация формы (деморежим)
- `consent.html` — Согласие на обработку персональных данных
- `policy.html` — Политика обработки персональных данных
- `assets/` — логотипы
- `server.js` — локальный сервер для превью (`npm run dev`, порт 7100)

## Локальный запуск

```bash
npm run dev
```

Затем открыть http://localhost:7100/

## Примечание

Демонстрационная версия: телефон, адрес, цены и отзывы — заполнители.
Форма обратного звонка работает в деморежиме, заявки никуда не отправляются.
